# Stellar Burgers

Учебный проект сервиса для сборки космических бургеров.

Проект выполнен в рамках курса **Middle Frontend Developer** от Яндекс Практикума.

## Функциональность

В приложении можно:

- просматривать список ингредиентов;
- переключаться между категориями «Булки», «Соусы» и «Начинки»;
- открывать подробную информацию об ингредиенте в модальном окне;
- добавлять ингредиенты в конструктор с помощью Drag and Drop;
- заменять выбранную булку;
- добавлять несколько одинаковых ингредиентов;
- удалять ингредиенты из конструктора;
- менять порядок ингредиентов внутри конструктора;
- видеть количество добавленных ингредиентов на карточках;
- автоматически рассчитывать итоговую стоимость бургера;
- оформлять заказ;
- получать реальный номер заказа от API.

## Drag and Drop

Для Drag and Drop используется библиотека `react-dnd`.

Поддерживается:

- перенос ингредиентов из списка в конструктор;
- замена булки;
- добавление одинаковых ингредиентов несколько раз;
- сортировка ингредиентов внутри конструктора;
- отмена изменения порядка при переносе ингредиента за пределы конструктора.

## Оформление заказа

При оформлении заказа на сервер отправляется массив `_id` выбранных ингредиентов.

ID булки передаётся первым и последним элементом массива:

```js
[
  bun._id,
  ...ingredients.map((ingredient) => ingredient._id),
  bun._id,
]
