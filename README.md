## Sprint 3

В третьем спринте проект был дополнен маршрутизацией, авторизацией и новыми страницами приложения.

### Реализовано

- Настроена маршрутизация с помощью `react-router-dom`.
- Созданы страницы:
  - главная `/`;
  - авторизация `/login`;
  - регистрация `/register`;
  - восстановление пароля `/forgot-password`;
  - сброс пароля `/reset-password`;
  - профиль пользователя `/profile`;
  - история заказов `/profile/orders`;
  - лента заказов `/feed`;
  - страница 404.
- Реализован динамический маршрут `/ingredients/:id`.
- При клике на ингредиент его информация открывается в модальном окне с изменением URL.
- При прямом переходе на `/ingredients/:id` открывается отдельная страница ингредиента.
- Добавлены защищённые маршруты для авторизованных и неавторизованных пользователей.
- После авторизации пользователь возвращается на страницу, к которой пытался получить доступ ранее.
- Реализованы:
  - регистрация;
  - вход;
  - выход;
  - получение данных пользователя;
  - редактирование профиля;
  - восстановление и сброс пароля.
- Добавлено хранение `accessToken` и `refreshToken`.
- Реализовано автоматическое обновление `accessToken` и повтор исходного запроса при истечении токена.
- Запросы, требующие авторизации, отправляются с заголовком `authorization`.
- Оформление заказа доступно только авторизованным пользователям.
- Сохранена функциональность предыдущих спринтов: конструктор бургера, Drag and Drop, счётчики ингредиентов и создание заказа.
