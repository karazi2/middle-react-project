# 5

Учебный проект курса «Middle Frontend-разработчик» Яндекс Практикума.

Приложение позволяет собирать бургер из ингредиентов, оформлять заказы, работать с авторизацией, просматривать общую ленту заказов и историю собственных заказов в реальном времени.

## Функциональность

### Конструктор бургеров

- загрузка ингредиентов с сервера;
- разделение ингредиентов на булки, соусы и начинки;
- добавление ингредиентов в конструктор через Drag & Drop;
- изменение порядка ингредиентов;
- удаление ингредиентов;
- автоматический подсчёт стоимости заказа;
- оформление заказа авторизованным пользователем;
- отображение номера созданного заказа.

### Авторизация

Реализованы:

- регистрация;
- вход;
- выход;
- восстановление пароля;
- изменение данных профиля;
- проверка авторизации при загрузке приложения;
- автоматическое обновление access-токена;
- защищённые маршруты.
